# PRD Generator - Salesoorja

Generate clear, structured Product Requirements Documents with measurable acceptance criteria.

## Process
1. Define Problem & Goals
2. Establish Scope & Out-of-Scope boundaries
3. Break down into discrete User Stories with verifiable Acceptance Criteria
4. Verify tests and safety constraints
